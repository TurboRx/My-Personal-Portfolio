# TurboRx - Personal Portfolio & Analytics

A fast, lightweight, and modern personal developer portfolio powered by Vanilla HTML, CSS, and JavaScript with GitHub API integration.

![Portfolio Preview](https://github.com/TurboRx.png)

## ✨ Features

- ⚡ **GitHub API Integration**: Real-time stats for stars, public repos, followers, and forked repos.
- 🎨 **Theme System**: Light, Dark, and System theme switching with smooth transitions.
- 🔍 **Live Search & Filter**: Instant repository search and language filtering.
- 🚀 **Live Demo Links**: Automatic detection of project demo links and GitHub topics.
- ⚡ **Performance & Caching**: Smart `localStorage` caching with fallback rate-limit handling.
- ♿ **Accessible & SEO Ready**: Open Graph meta tags, SVG favicon, and full keyboard navigation support.

## 🚀 Quick Start

No build step required! Simply clone and open `index.html` in your browser:

```bash
git clone https://github.com/TurboRx/My-Personal-Portfolio.git
cd My-Personal-Portfolio
# Open index.html in your browser or run a local static server:
npx serve .
```
